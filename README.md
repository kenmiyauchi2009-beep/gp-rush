# GPラッシュ

iPhone のホーム画面に追加して、機内モードでも遊べる擬似3Dのフォーミュラレース。
素の HTML / CSS / JavaScript（ES Modules）だけで動き、外部通信はしません。画像も音もコードで作っています。
チーム・ドライバー・サーキット・スポンサーはすべて架空です。

## 遊び方

1. タイトルで「ライバル」の強さ（やさしい・ふつう・むずかしい）を選ぶ。
   - **シーズン**：全8戦。各戦は予選（1周のタイムアタック）→ 決勝。予選をとばすと12番手から。上位10台にポイント（25・18・15・12・10・8・6・4・2・1）。8戦のあとにチャンピオンが決まる。
   - **クイックレース**：サーキットを選んで1レース（10番手から）。
   - **練習走行**：サーキットを選んで1人で走る。
2. 信号が5つ点いて、全部消えたらスタート。アクセルは自動。
3. **画面の左半分を押すと左、右半分を押すと右**に曲がる。**左右を両方押すとブレーキ**。
4. レースは20台・3周。左上に順位（POS）と周回（LAP）、その下に前後の車との差（秒）が出る。
5. ゴールすると結果の表が出る（順位・タイム・各自のベストラップ。いちばん速い周は紫）。
6. 1周ごとにタイムが出て、このコースでいちばん速い周が「ベスト」として残る。
7. 左上のボタンで一時停止（続ける・やり直す・音のON/OFF・タイトルへ）。

### 走り方のコツ

- 速いままきついカーブに入ると、外側へ振られて芝やグラベルに出る。芝は減速、グラベル（コーナーの外の砂）は大きく減速する。
- ヘアピンやシケインの手前では、両方押しでブレーキ。距離の看板（300・200・100）が目印。
- ハンドルを切っているあいだも少しずつ減速する。まっすぐ走れるところは、まっすぐ走る。
- 看板・観客席・木・タイヤバリアにぶつかると大きく減速する。
- 前の車の真後ろにつくと、空気の抵抗が減って少し速くなる（スリップストリーム）。ストレートで近づいて、横に出て抜く。
- 前の車に追突すると、その車の速さまで落ちる。

### チーム（すべて架空）

自分は「GPラッシュ・ワークス」（チームメイトはハル・ミナミ）。ライバルは、オーロラ・レーシング、キツネ・モータースポーツ、ヴェルダント、ソラーノ・コルセ、ノルトヴィント、ハルシオンGP、コーラル・ブルー、メリディアン、ツンドラ・レーシングの9チーム18人。チームの速さとドライバーの腕に差がある（`js/data.js`）。

## iPhone に入れる

1. Safari で公開ページを開く。
2. 共有ボタン →「ホーム画面に追加」。
3. ホーム画面のアイコンから一度起動して、閉じて、もう一度開く。一時停止メニューの下に「オフライン：有効」と出れば機内モードでも起動できる。

横向きで遊ぶ（縦向きのときは「横向きにしてください」と出る）。

## 開発メモ

- 手元で動かす：`python3 tools/serve.py` を実行して http://localhost:8123 を開く（ブラウザがファイルを覚えないサーバー）。
  localhost では service worker を使わない（古いファイルが残らないように）。試すときは `?sw=1` を付ける。
- ファイルを更新したら `sw.js` の `VERSION` と `js/main.js` の `APP_VERSION` を上げる。ファイルを増やしたら `sw.js` の `ASSETS` にも足す。
- アイコンは `python3 tools/make_icons.py`（Pillow が必要）で作り直す。
- コンソールで `T.G.autoDrive = true` にすると、自分の車が自動で走る（確認用）。
- 調整用の値：車の速さ・曲がりやすさは `js/physics.js` の `CAR`、コースの形は `js/track.js` の `COURSES`（順番は `CALENDAR`）、景色は `js/themes.js`、ライバルの強さは `js/data.js` の `DIFFS`。

| ファイル | 中身 |
| --- | --- |
| `js/main.js` | 起動・画面の流れ・毎フレームの処理 |
| `js/track.js` | コースの定義と組み立て・景色の配置・小さな地図 |
| `js/render.js` | 擬似3Dの描画（道・背景・観客席・景色・車） |
| `js/physics.js` | 車の動き・自動運転 |
| `js/race.js` | レースの進行（グリッド・ライバルの運転・接触・周回と順位・結果） |
| `js/data.js` | 架空のチーム・ドライバー・難易度 |
| `js/season.js` | シーズンのポイント・順位表・予選のタイム |
| `js/themes.js` | サーキットごとの景色（空・霧・芝・背景・木・時間帯の色味） |
| `js/sprites.js` | 景色の絵（木・観客席・看板・やぐら など） |
| `js/carart.js` | 後ろから見たマシンの絵 |
| `js/input.js` | タッチとキーボードの操作 |
| `js/hud.js` | タイム・速さ・ギア・地図の表示 |
| `js/audio.js` | エンジン音・信号の音（コードで作る） |
| `js/save.js` | セーブ（localStorage） |
| `js/offline.js` | service worker の登録 |
