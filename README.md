# GPラッシュ

iPhone のホーム画面に追加して、機内モードでも遊べる擬似3Dのフォーミュラレース。
素の HTML / CSS / JavaScript（ES Modules）だけで動き、外部通信はしません。画像も音もコードで作っています。
チーム・ドライバー・サーキット・スポンサーはすべて架空です。

## 遊び方

1. タイトルで「ライバル」の強さ（やさしい・ふつう・むずかしい）と「周回」（3周・5周・8周）を選ぶ。
   - **シーズン**：全8戦。各戦は予選（1周のタイムアタック）→ 決勝。予選をとばすと12番手から。上位10台にポイント（25・18・15・12・10・8・6・4・2・1）。8戦のあとにチャンピオンが決まる。
   - **クイックレース**：サーキットを選んで1レース（10番手から）。
   - **練習走行**：サーキットを選んで1人で走る。
   - **ガレージ**：パーツの付け替え・強化・分解と、パーツ箱のショップ。
2. 信号が5つ点いて、全部消えたらスタート。アクセルは自動。
3. **画面の左半分を押すと左、右半分を押すと右**に曲がる。**左右を両方押すとブレーキ**。
4. レースは20台。スタート前にタイヤを選ぶ。左上に順位（POS）と周回（LAP）、その下に前後の車との差（秒）、右下にタイヤの残り（%）が出る。
5. ゴールすると結果の表が出る（順位・タイム・各自のベストラップ。いちばん速い周は紫）。
6. 1周ごとにタイムが出て、このコースでいちばん速い周が「ベスト」として残る。
7. 左上のボタンで一時停止（続ける・やり直す・音とBGMのON/OFF・タイトルへ）。
8. レースの途中でアプリを閉じても、次に開くとタイトルに「続きから」が出る（3秒ごとと、裏に回ったときに保存）。
9. タイトル右上：トロフィー＝**実績と記録**、歯車＝**設定**。

### 走り方のコツ

- 速いままきついカーブに入ると、外側へ振られて芝やグラベルに出る。芝は減速、グラベル（コーナーの外の砂）は大きく減速する。
- ヘアピンやシケインの手前では、両方押しでブレーキ。距離の看板（300・200・100）が目印。
- ハンドルを切っているあいだも少しずつ減速する。まっすぐ走れるところは、まっすぐ走る。
- 看板・観客席・木・タイヤバリアにぶつかると大きく減速する。
- 前の車の真後ろにつくと、空気の抵抗が減って少し速くなる（スリップストリーム）。ストレートで近づいて、横に出て抜く。
- 前の車に追突すると、その車の速さまで落ちる。

### 天気・タイヤ・ピット

- 天気はレースごとに **晴れ・くもり・雨**（砂漠は雨が降らない）。シーズンでは天気予報が出る。雨の日は路面が滑り、霧が濃く、前の車の水しぶきで見えにくい。
- タイヤは4種類。周回が多いほどタイヤの作戦が大事になる（5周以上）。

| タイヤ | 晴れのグリップ | 雨のグリップ | 1周で減る | 向いているとき |
| --- | --- | --- | --- | --- |
| ソフト（赤） | 105 | 74 | 約24% | 短いレース |
| ミディアム（黄） | 100 | 73 | 約15% | バランス型 |
| ハード（白） | 96 | 72 | 約9% | 長いレース |
| レイン（青） | 90 | 87 | 約12%（晴れだと約35%） | 雨 |

- タイヤは60%減ると急に滑りやすくなる。
- **ピット**：左の「PIT」ボタン → 替えるタイヤを選ぶ。次にスタートラインを通るときに止まって交換する（約9秒）。もう一度押すと取り消し。ライバルもタイヤが減ったり天気に合わなかったりするとピットに入る。
- 1位がゴールすると、周回遅れの車はラインを越えたところでゴールになる。
- 賞金は周回が多いほど多い（3周を1として、5周で約1.4倍、8周で約2倍）。

### 音

エンジン・タイヤのきしみ・風・芝や縁石の振動・近くのライバルのエンジン・雨の音。メニューではコードで作った BGM が流れる。一時停止メニューで「音」と「BGM」を別々に ON/OFF できる。

### 設定

- 音：効果音とBGMの ON/OFF と音量。
- 操作：ハンドルの効き（ゆっくり・ふつう・すばやい）、**ブレーキアシスト**（速すぎるとカーブの手前で自動でブレーキ。両方押しが苦手なときに）。
- 画面：画質（きれい・ふつう・省電力）。省電力は解像度を下げ、遠くを描く距離を短くして、1秒に30回だけ描く。メニューの画面はいつも30回。
- セーブ：書き出す（文字にしてコピー）・読み込む（貼り付け）・すべて消す。

### 実績（24個）

はじめてのゴール・表彰台・初優勝・ポールポジション・ファステストラップ・ごぼう抜き（10台抜き）・大逆転（12番手以下から優勝）・ノーミス・雨の勝者・夜の勝者・ロングレース・作戦勝ち・本気のライバル・サーキット制覇・シーズン完走・チャンピオン・10レース・50レース・10勝・稼ぎ頭・エピック・レジェンド・鍛え上げ・モンスターマシン。達成すると CR がもらえる。「記録」には通算成績・サーキットごとのベストラップ・最高順位・優勝回数・歴代シーズンが出る。

### マシン育成（ガレージ）

- レースのあとに **賞金（CR）** と **パーツ1つ** をもらえる。賞金は順位で決まり、シーズン戦は1.5倍。ポールポジション（+200）とファステストラップ（+150）にボーナス。上位ほどレアなパーツが出やすい。
- パーツは5つの部位：エンジン（最高速）・ギアボックス（加速）・空力（コーナー）・タイヤ（グリップ）・ブレーキ。
- レア度：ノーマル → コモン → アンコモン → レア → エピック → レジェンド。アンコモン以上には **付与効果**（ほかの性能・芝やグラベルで減速しにくい・スリップストリーム・接触に強い）が付く。
- **強化**：CR でレベルを上げる（最大10）。**分解**：いらないパーツを CR に戻す。所持品は40個まで。
- **ショップ**：スポーツの箱（500 CR）・レーシングの箱（1,500 CR）・ワークスの箱（4,000 CR）。部位はランダム。
- 戦力：装着しているパーツの強さをまとめた数字（ノーマルで1000）。
- 目安：レジェンド・Lv10 をそろえると「ふつう」なら勝てる速さ、「むずかしい」で上位争いになる。

### チーム（すべて架空）

自分は「GPラッシュ・ワークス」（チームメイトはハル・ミナミ）。ライバルは、オーロラ・レーシング、キツネ・モータースポーツ、ヴェルダント、ソラーノ・コルセ、ノルトヴィント、ハルシオンGP、コーラル・ブルー、メリディアン、ツンドラ・レーシングの9チーム18人。チームの速さとドライバーの腕に差がある（`js/data.js`）。

## iPhone に入れる

1. Safari で公開ページを開く。
2. 共有ボタン →「ホーム画面に追加」。
3. ホーム画面のアイコンから一度起動して、閉じて、もう一度開く。一時停止メニューの下に「オフライン：有効」と出れば機内モードでも起動できる。

横向きで遊ぶ（縦向きのときは「横向きにしてください」と出る）。

## 作った順番（フェーズ）

1. ✅ 土台：擬似3Dの道・左右タップの操作・ラップ計測・オフライン
2. ✅ レース：ライバル車（AI）・接触・スリップストリーム・順位・3周のレース・結果画面・道に沿った観客席
3. ✅ シーズン：サーキット8つ（景色と時間帯が違う）・予選・ポイント・順位表・チャンピオン
4. ✅ マシン育成：賞金・パーツ（5部位・レア度・付与効果）・強化と分解・ショップ・ガレージ
5. ✅ 演出：天気（雨・くもり）・タイヤの種類と摩耗・ピット・効果音とBGM・カメラの傾き
6. ✅ 仕上げ：途中から再開・設定（音量・ハンドル・ブレーキアシスト・画質・セーブの書き出し）・実績と記録・省電力

## 開発メモ

- 手元で動かす：`python3 tools/serve.py` を実行して http://localhost:8123 を開く（ブラウザがファイルを覚えないサーバー）。
  localhost では service worker を使わない（古いファイルが残らないように）。試すときは `?sw=1` を付ける。
- ファイルを更新したら `sw.js` の `VERSION` と `js/main.js` の `APP_VERSION` を上げる。ファイルを増やしたら `sw.js` の `ASSETS` にも足す。
- アイコンは `python3 tools/make_icons.py`（Pillow が必要）で作り直す。
- コンソールで `T.G.autoDrive = true` にすると、自分の車が自動で走る（確認用）。
- 調整用の値：車の速さ・曲がりやすさは `js/physics.js` の `CAR`、コースの形は `js/track.js` の `COURSES`（順番は `CALENDAR`）、景色は `js/themes.js`、ライバルの強さは `js/data.js` の `DIFFS`、パーツの強さと値段は `js/parts.js` の `STATS`・`upgradeCost`・`BOXES`。
